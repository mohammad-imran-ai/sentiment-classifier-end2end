# sentiment-classifier-end2end
# An end-to-end sentiment classification pipeline for product reviews: data ingestion and cleaning, feature extraction, PyTorch model training, evaluation, and a FastAPI inference service packaged with Docker. Includes reproducible scripts, a demo GIF (or hosted link), and step-by-step quick start to run locally or in a container.

 Problem: classify product reviews as positive/negative.
 Deliverables: preprocessing scripts, training pipeline (PyTorch), evaluation notebooks, FastAPI + Docker deployment, demo media, and reproducibility notes. 
 
 Quick start: clone → pip install -r requirements.txt → python run_demo.py or docker-compose up.
